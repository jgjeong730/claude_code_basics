클로드 코드, 처음 만나는 시간

제미나이와 챗GPT는 이미 손에 익히신 이사님께, 코드를 직접 다루는 AI는 무엇이 다른지 차근차근 소개해 드립니다.

초급 안내서 2026. 08

시작하며이미 절반은 알고 계십니다

이사님은 제미나이·챗GPT로 글을 다듬고, 유튜브 영상을 편집·업로드하고, 블로그와 연동하는 과정을 이미 몸에 익히셨습니다. 클로드 코드는 그 경험의 다음 단계에 있는 도구일 뿐입니다.

다른 점은 하나입니다. 지금까지의 AI는 대화창 안에서 말로 답해 주었다면, 클로드 코드는 컴퓨터 안의 실제 파일과 프로그램을 직접 열고, 고치고, 실행합니다.

01 · 비교대화하는 AI와 실행하는 AI

챗GPT · 제미나이 클로드 코드
하는 일 질문에 답하고 글을 써줌 파일을 직접 열어 고치고 실행함
결과물 채팅창 속 텍스트 실제 폴더 속 파일과 결과물
작업 방식 한 번 묻고 한 번 답함 여러 단계를 스스로 이어가며 끝까지 수행
비유 "이 내용 요약해줘"라고 부탁하는 비서 "이 폴더를 정리하고 실행까지 해줘"라고 맡기는 조수

02 · 개념코딩이란, 아주 꼼꼼한 지시서

코딩은 거창한 것이 아닙니다. 컴퓨터가 알아듣는 말로, 순서를 하나하나 빠짐없이 적어놓은 지시서입니다. 영상 편집 프로그램의 '매크로'나 '액션'과 비슷합니다 — 반복되는 작업을 순서대로 정리해두면, 다음부터는 그 순서를 그대로 실행하는 것이죠.

비유 클로드 코드는 이사님이 말로 "이렇게 해줘"라고 설명하면, 그 말을 컴퓨터용 지시서(코드)로 스스로 옮겨 적고 대신 실행해 주는 조수입니다. 지시서를 직접 쓰실 필요는 없습니다.

03 · 능력클로드 코드가 실제로 하는 일

읽

파일을 읽고 씁니다

문서나 목록을 직접 열어 확인하고, 필요하면 내용을 고치거나 새로 만듭니다.

행

명령을 실행합니다

프로그램을 켜고, 정리하고, 결과를 확인하는 작업을 대신 처리합니다.

잇

단계를 스스로 이어갑니다

"이것도 하고 저것도 해줘"라고 하면 순서를 스스로 짜서 끝까지 진행합니다. 이런 성격의 AI를 '에이전트'라고 부릅니다.

04 · 사례이사님의 작업으로 옮겨보면

유튜브 영상 200개의 파일명을 날짜별로 정리하고, 그 중 조회수 상위 10개만 골라 블로그에 올릴 목록을 만든다고 가정해 보겠습니다.

챗GPT·제미나이라면 "파일명은 이런 규칙으로 정리하시고, 정렬은 이렇게 하시면 됩니다" — 방법을 알려주는 데서 끝납니다. 실제 정리는 이사님이 손으로 하셔야 합니다.
클로드 코드라면 실제 폴더에 들어가 파일명을 직접 정리하고, 조회수를 확인해 상위 10개를 골라내고, 블로그에 올릴 목록 파일까지 만들어 드립니다.

05 · 용어먼저 알아두면 편한 말 다섯 가지

터미널
컴퓨터에게 글로 명령을 내리는 창. 마우스 클릭 대신, 문장으로 대화하듯 명령을 주고받는 곳입니다.
폴더와 파일
컴퓨터 속 서류함과 서류. 클로드 코드는 이 서류함 안에서 실제로 작업합니다.
프롬프트
이사님이 입력하시는 요청 문장. 챗GPT에 쓰시던 것과 완전히 같은 개념입니다.
에이전트
지시를 받으면 스스로 여러 단계를 계획하고, 끝까지 실행까지 마치는 AI를 가리키는 말입니다.
권한 승인
중요한 작업 전에 "이렇게 진행해도 될까요?"라고 먼저 여쭤보는 안전장치입니다.
세션
클로드 코드와 나누는 한 번의 대화 전체. 유튜브 라이브 방송 한 회차와 비슷하게, 시작과 끝이 있습니다.

06 · 예시실제 대화는 이런 모습입니다

이사님
이번 달 유튜브 영상 목록을 정리해줘. 파일명, 업로드 날짜, 조회수를 표로 만들어줘.
클로드 코드
videos 폴더 확인 중 · 파일 37개 발견 · 조회수 정렬 중…

표를 만들어 영상목록.xlsx로 저장했습니다. 상위 10개도 따로 표시해 두었는데, 확인해 보시겠어요?

07 · 안심시작 전에 알아두시면 좋은 점

클로드 코드는 파일을 지우거나 되돌리기 어려운 작업을 하기 전에는 반드시 먼저 여쭤봅니다. 대부분의 실수는 되돌릴 수 있고, 처음에는 "이 폴더에 어떤 파일들이 있는지 보여줘" 같은 가벼운 질문부터 시작하시면 충분합니다.

08 · 다음이렇게 시작해보시길 권합니다

설치 후 가벼운 질문 하나 던져보기

"지금 폴더에 무슨 파일이 있어?" 정도의 부담 없는 질문으로 첫 대화를 시작합니다.

평소 반복하시던 작업 하나를 골라 맡겨보기

영상 파일 정리처럼 손이 많이 가던 작업 하나를 부탁드려 봅니다.

결과를 확인하고 요청을 다듬어보기

결과가 원하시는 것과 다르면, 이어서 "이 부분은 이렇게 고쳐줘"라고 편하게 다시 요청합니다.

익숙해지면 유튜브·블로그 작업과 연결해보기

이미 잘 아시는 영역에 접목하면 클로드 코드의 쓸모가 가장 빠르게 와닿으실 겁니다.

이 안내서는 이사님과의 첫 대화를 위해 정리되었습니다.
